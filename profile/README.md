# TaughtRight

**On-the-job training for AI agents.**

The labs trained the model. TaughtRight trains your agent.

- **Teach it once.** Every correction you give an agent becomes a lesson.
- **We check that it stuck:** a week later, after every upgrade, on any model.
- **You get proof**, and a fix when it forgets.

Built on UTL, a unified theory of learning.
